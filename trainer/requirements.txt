# TRAINER environment: Unsloth + TRL + vLLM on one NVIDIA GPU (24 GB). Python 3.12, CUDA 12.8 wheels.
# Tested on an RTX 5090 Laptop GPU (Blackwell), WSL2 Ubuntu, NVIDIA driver 592.00.
#
# This is NOT the server environment. The NeMo Gym resources server has its own environment and its own file:
#   NeMo_Gym/resources_servers/mission_search/requirements.txt   (Python 3.13, CPU-only torch)
# The two environments share no package. They talk over HTTP only. Never install one list into the other.
#
# Install from this folder. Always the whole list in ONE command, never one package alone (docs/Dependency_hell.md, section 2):
#   uv venv .venv --python 3.12 --seed
#   uv pip install --python .venv/bin/python --override overrides.txt -r requirements.txt
# --override is needed: Unsloth 2026.9.12 declares trl<=0.24.0 and transformers<=5.5.0, which are stale (see overrides.txt).
# Do not add --torch-backend or an extra index: with --torch-backend cu128 the resolver looks for torchao only on the PyTorch index and fails
# (checked 2026-10-31). torch and torchvision are pinned by wheel URL instead, as in the server file, so they stay the CUDA 12.8 builds.
# A plain torch==2.11.0 would resolve to the PyPI build, which pulls a different mix of CUDA packages.
# After the install, `pip check` must report exactly two problems (unsloth wants trl and transformers below the pinned versions). Any other line is new.
# Not needed on WSL2: the env var VLLM_WSL2_ENABLE_PIN_MEMORY=1. train_grpo.py sets it before vLLM loads.
